# Cyber Anomaly Detection System

## 📌 Overview
This project detects anomalous behavior in server logs using machine learning techniques.

## 🚀 Features
- Log parsing and preprocessing
- Anomaly scoring
- Visualization of suspicious IPs
- Flask dashboard for monitoring

## 🛠️ Tech Stack
- Python
- Pandas
- Scikit-learn
- Flask
- Matplotlib

## 📊 How it works
1. Parse logs
2. Extract features
3. Train anomaly detection model
4. Detect abnormal patterns
5. Visualize results

## ▶️ Run the project
```bash
pip install -r requirements.txt
python dashboard.py
